# AI Coding Agent

A Python CLI agent that uses an LLM plus file-system tools to inspect, edit, and run code in a local project.

## Features

- Lists project files
- Reads file contents
- Writes updates to files
- Runs Python programs
- Uses tool calls to diagnose and fix bugs

built as part of the Boot.dev backend curriculum.
